## 4. 可替代料

| 原型号 | 替代 | 注意 |
|---|---|---|
| TCA9534A | PCA9534A（TSSOP-16） | 同寄存器/同方向控制；**不要用 PCF8574**（无方向寄存器，整字节写会把按键和 ALERT 拉低） |
| INA226 | MAX17048 模块 | 只给电压/SOC，不给电流；I2C 地址 0x36 |
| BSS138 | 2N7002 / AO3400（注意 Vgs） | 2N7002 栅极耐压够；AO3400 是功率 MOS，不要用 |
| BC547 | 2N3904 | 引脚排列不同，按丝印 |
| IP5306 模块 | IP5306 I2C 版 | 可关自动关机；但按键逻辑/寄存器不同，固件要改 |
| OV2640 | OV5640 | 不是 drop-in，引脚/时钟/驱动不同；第一版不要换 |
| MAX98357A | PCM5102 + PAM8403 | 多两颗芯片，I2S 配置不同；不推荐第一版 |
| GC9A01 1.28" | ST7735 1.8" 方屏 | 不是圆脸；外壳要重画 |

## 5. 不要买

- **无保护板的锂电芯**；鼓包、反接、过放都可能起火。
- **5V 版 GC9A01** 直接上 3.3V；不亮或发热。
- **0.5A 或 1.5A PTC**；1.2A 峰值和壳体降额会跳，用 2A hold / 4A trip。
- **按键焊盘不可接线的 IP5306 模块**；做不了心跳/软关机。
- **排针顺序不明的 OV2640**；必须让卖家给丝印图或实物照。
- **4Ω 喇叭**；电流大、发热大。
- **没有 VBUS/IN+/IN- 标注的 INA226 模块**；接线容易错。

## 6. 下单顺序

1. **先买模块 + 控制/电源小件**，不买 PCB。
2. 到货先核对：DevKitC 版本、OV2640 排针、屏幕电压、IP5306 按键焊盘、电池极性/尺寸。
3. 面包板跑通 P1/P2/P3；记录实际排针和电压。
4. 再画 PCB、打样。
5. 最后买 3D 打印外壳；先纸板 1:1 试装。
6. 电池单独下单，别和板子一起压；收到先量电压、看保护板。

## 7. 工具

- 万用表（必须）
- 烙铁 + 焊锡 + 吸锡带 + 助焊剂
- USB-C 数据线（能传数据，不是只充电）
- 5V 2A 电源 / 充电头
- 剪线钳、剥线钳、热缩管
- 杜邦线、面包板
- 可选：示波器、直流电子负载、热风枪

没有示波器可以，先用万用表和串口；电源问题先量 5V/3.3V，再怀疑程序。
