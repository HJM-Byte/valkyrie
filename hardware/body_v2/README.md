# 瓦尔基里 · 身体板 v2（模块化，Ø120）

v2 在 v1 的摄像头/屏幕/麦克风/喇叭/WiFi/电池上，新增 **POWER、PROACTIVE、VOICE** 三个面板键，并把电源做成可开关、可心跳、可读电量的一套。板从 Ø100 放大到 Ø120，原因是 DevKitC 的 2×22 模块四角在 Ø100 内会切掉；外壳同步为 Ø124。

## 三句话

1. **大脑还在 PC。** ESP32-S3 只做身体；电源键只关身体，不关 PC。
2. **电源键硬件直连 IP5306。** MCU 用 NPN 做心跳/软关机，用 BSS138 读键；固件挂了，长按 >2 秒仍能断电。
3. **语音/主动消息键走 TCA9534。** PC 持久化开关，手机同步；关语音时 P6 高、Q3 把功放 `SD` 拉低，关主动消息时不生成、不投递。

## 不是什么

**不是已经布好线的 Gerber。** 板框、摆位、接线、BOM 已定；原理图连线、PCB 走线、DRC、Gerber 还没做。P6 才出生产文件。

## 下单顺序

1. **先买模块，不画板。** 按 BOM 买一套，用杜邦线在桌面上跑通屏/摄像头/麦克风/喇叭。
2. 按 `接线表.csv` 核每个模块的实际排针；OV2640 各家顺序不同，不能盲插。
3. 电源先单独台架：电池 → INA226 → IP5306 → 5V；面板键开关；心跳 12s；软关机 2.5s。
4. 再画 PCB；DRC/Gerber 过了再上传嘉立创。
5. 最后做外壳；先纸板 1:1 试装，再 3D 打印。

## 关键约束

- **DevKitC 必须 v1.1**；v1.0 的 RGB LED 在 GPIO48，会和 v2 的 IP5306_KEY 冲突。
- **屏幕 CS 接地、RST 接 EN**：SPI 只有 GC9A01 一个从设备；RST 跟 MCU 复位，省出 GPIO48。
- **I2C 共用摄像头 SCCB**：OV2640 0x30、TCA9534 0x20、INA226 0x40；esp32-camera 要支持 `sccb_i2c_port`。
- **KEY 是电池域**：可能 4.2V，不能直接接 ESP32 GPIO；KEY 先串 R5 100k 到 BSS138 栅极，栅源 R6 100k 下拉，不装 5.1V 稳压管。
- **PTC 用 2A hold / 4A trip**，装在 5V 总入口；不要用 0.5A 或 1.5A。
- **功放 SD 用 Q3 低边关断**：P6 高=关断；SD 是通道选择脚，GAIN 才是增益脚，两者别混。
- **喇叭开在后壳**，Ø28；前面板不放喇叭，避免和屏幕/按键抢位置。
- **天线正下方 15×28mm 两层禁铜**：`(63,10)–(78,38)`；外壳塑料，电池不贴天线。
- **后壳左侧开 DevKitC 双 USB 缺口**，装壳后也能烧写；模块离板边约 10mm，用一根 USB-C 90° 公对母短线引到侧槽。
