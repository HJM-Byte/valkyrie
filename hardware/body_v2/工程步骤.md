# v2 工程动手步骤

按顺序做，不要跳。每一步都有“通过标准”；不通过就停在这一步，不要先装壳、先打板。

## 0. 先准备

**工具**：万用表、烙铁、焊锡、吸锡带、助焊剂、USB-C 数据线、5V 2A 电源、剪线钳、剥线钳、热缩管、杜邦线、面包板。

**安全**：

- 电池必须带保护板；先量正负极，再插 JST。
- 不要边充电边用最大音量长测；充电时不要盖壳。
- 烙铁用完断电；焊完先检查短路再上电。
- 第一次上电用限流电源或串一个小电阻/保险丝；不要直接怼电池。

## 1. P0：纸面与采购

- [ ] 打印 `board_top_v2.png`、`board_bottom_v2.png`、`panel_cutout_v2.png`，按 120mm 板 / 124mm 面板实际尺寸打纸板。
- [ ] 按 `BOM_采购.csv` 下单：先买模块、TCA9534、INA226、IP5306、按键、阻容；**不买 PCB**。
- [ ] 到货核对：DevKitC 是否 v1.1，OV2640 2×9 排针顺序，GC9A01 是否 3.3V，IP5306 是否有可焊按键焊盘，电池尺寸/极性。
- [ ] 纸板 1:1 摆一遍：屏幕、摄像头、按键、电池、IP5306 是否打架。

**通过标准**：所有模块型号/电压/排针确认；纸板上按键位置手指能按到，屏幕不挡摄像头。

## 2. P1：电源台架（先不插 DevKitC）

### 2.1 电池与 IP5306

- [ ] 万用表量电池电压：3.6–4.2V；量电池 JST 极性。
- [ ] 电池 + → INA226 `IN+`；INA226 `IN-` → IP5306 `BAT+`；所有 GND 共地。
- [ ] IP5306 不接负载，短按模块按键：量 5V 输出应为 4.8–5.1V。
- [ ] 接 100Ω/10W 假负载：5V 不应掉到 4.7V 以下；IP5306 不烫。

**注意**：INA226 模块如果自带 0.01Ω，不要再外接；`IN+`/`IN-` 就是分流两端。没有 `VBUS` 脚就用 `IN+` 读电池电压。

### 2.2 面板电源键

- [ ] 面板 POWER 键一端接 IP5306 `KEY`，一端接 GND。
- [ ] 关机状态短按：5V 应开；再长按 >2s：5V 应关。
- [ ] 用万用表量 `KEY` 高电平（未按）；记录是电池域还是 5V 域。

**通过标准**：短按开机、长按关机；按键不卡、不连锡。

### 2.3 心跳与检测

- [ ] 焊 Q2 NPN：集电极 → `KEY`，发射极 → GND，基极 → 1k → GPIO48；基极-发射极 10k 下拉。
- [ ] 焊 Q1 BSS138：`KEY → R5 100k → 栅极`；`栅源 R6 100k`；源极 → GND，漏极 → GPIO1；漏极 10k 上拉 3V3；**不装 5.1V 稳压管**。
- [ ] 先不插 DevKitC：用 3.3V 手动点 GPIO48，量 `KEY` 是否被拉低；松手是否回高。
- [ ] 用 3.3V 手动拉 Q1 栅极（或按 S1），量 GPIO1 是否翻转。
- [ ] 量“挂 R5/R6 前”和“挂上后”的 KEY 高电平；差应 <0.3V，否则把 R5/R6 加到 1M。

**通过标准**：GPIO48 高 → KEY 低；S1 按下 → GPIO1 高；松手恢复；KEY 高电平被加载 <0.3V。

### 2.4 心跳固件

- [ ] 插 DevKitC，烧最小固件：每 12s 拉高 GPIO48 100ms；串口打印心跳。
- [ ] 不接任何外设，只接 IP5306 5V；观察 2 分钟，5V 不应自动掉。
- [ ] 拔掉心跳（改 60s 一次），确认 32s 左右 IP5306 会待机——验证心跳确实有用。

**通过标准**：12s 心跳下 2 分钟不掉电；停止心跳后约 32s 掉电；软关机 GPIO48 高 2.5s 能关 IP5306。

## 3. P2：DevKitC 外设

### 3.1 只插 DevKitC

- [ ] USB 识别串口；`idf.py monitor` 有启动日志。
- [ ] WiFi 扫描能看到 2.4G 列表。
- [ ] 量 DevKitC 3.3V：3.2–3.4V。

### 3.2 屏幕

- [ ] 屏幕 VCC 3.3V、GND、DIN=GPIO47、CLK=GPIO21、DC=GPIO3、CS=GND、RST=EN（经 100Ω）、BL=3V3 经 10Ω。
- [ ] 烧屏幕测试：红/绿/蓝/白四屏；确认方向；断电/上电 20 次不应花屏。

**注意**：CS 接地后，SPI 只能有这一个设备；不要再并第二块 SPI 屏。

### 3.3 摄像头

- [ ] 按 `接线表.csv` 接 3V3/GND/SIOC/SIOD/VSYNC/HREF/PCLK/XCLK/D0–D7；PWDN 接 GND；RESET 3V3 RC。
- [ ] **对着模块丝印一根一根核**，不要按物理位置直插。
- [ ] 读传感器 ID；出 640×480 JPEG 到串口/PC。

**通过标准**：读 ID 正确；单张 JPEG <300ms；PC 能解码。

### 3.4 麦克风与喇叭

- [ ] INMP441：3V3/GND/SCK=GPIO41/WS=GPIO42/SD=GPIO39/LR=GND。
- [ ] 串口打印 RMS；对着麦克风说话，数字明显跳。
- [ ] MAX98357A：VIN=5V/GND/BCLK=GPIO41/LRC=GPIO42/DIN=GPIO40/SD 先接 3V3。
- [ ] 先放 1kHz 正弦，再放 16k 语音；1m 内清楚。
- [ ] 半双工：说话时喇叭响，确认没有持续啸叫；有就固件切半双工。

**通过标准**：麦克风 30ms 帧；喇叭 1m 清楚；无持续自激。

## 4. P3：控制面板

### 4.1 I2C 扫描

- [ ] TCA9534 VCC=3V3、GND、SDA=GPIO4、SCL=GPIO5；A0–A2 接地。
- [ ] INA226 VCC=3V3、GND、SDA/SCL 同总线；A0/A1 接地。
- [ ] 烧 I2C 扫描：应看到 0x20（TCA9534）、0x30（OV2640）、0x40（INA226）。

**如果不稳**：先拔摄像头，只留 TCA9534/INA226；确认 2.2k 上拉；再看 esp32-camera 是否支持共享 SCCB。退路：I2C 改 GPIO43/44，牺牲 UART。

### 4.2 按键与 LED

- [ ] TCA9534 P0 → PROACTIVE 键 → GND；P1 → VOICE 键 → GND；P0/P1 各 10k 上拉 3V3。
- [ ] P3 → 语音 LED 阴极；P4 → 主动 LED 阴极；P7 → 电源 LED 阴极；LED 阳极各 1k 到 3V3。
- [ ] P6 → 100k → Q3 栅极；Q3 栅源 100k 下拉，源极 GND，漏极 → MAX98357A SD；P6 **高**时功放关断。
- [ ] P5 → 5V 经 100k:150k 分压，节点加 100nF；P2 → INA226 ALERT + 10k 上拉。
- [ ] 烧测试：读 P0/P1；写 P3/P4/P6/P7；按键/LED 一一对应；P6 高时 SD <0.16V，P6 低时 SD 回到模块默认。

**通过标准**：按键 25ms 消抖；LED 不鬼影；P6 高时功放真的静音；P5 在 5V 时读到 2.9–3.0V。

### 4.3 电量计

- [ ] INA226 读电压/电流；与万用表比，电压差 <2%。
- [ ] 设 ALERT 3.5V；放电到阈值时 P2 翻转。
- [ ] 充电时电流方向为正/负与代码约定一致。

**通过标准**：电池电压、电流、低电告警都能读；手机/串口显示正确。

## 5. P4：固件

- [ ] 建立 `robot/firmware/body_v2/`，按 `board_pins.h` 固定引脚。
- [ ] 按键任务：直连键 + TCA9534 键，25ms 消抖；事件队列。
- [ ] 电源任务：12s 心跳、POWER 按下时长、软关机、低电。
- [ ] 协议：hello/state/face/snap/ctrl/event/battery/ping。
- [ ] 先连 PC 假身体：WS 连接、心跳、事件、断线重连。
- [ ] 再连真身体：按键事件到 PC，PC 回 ctrl，LED/AMP_SD 同步。

**通过标准**：假身体 10 分钟不掉线；真身体按键→PC→LED 全通；电源键软关机可靠。

## 6. P5：PC 与手机

- [ ] 新增 `app/body_control.py`：持久化 `data/body_controls.json`，原子写。
- [ ] `pocket_server` 增加 `GET /api/state` 的 `controls`、`POST /api/control`。
- [ ] `proactive.can_send()` 加运行时开关；关闭时不生成/不投递。
- [ ] `/api/tts` 在 voice 关时返回 `409 VOICE_OFF`。
- [ ] `body_link.py` 连接时下发 ctrl；收到 event 调 body_control；battery 更新手机。
- [ ] 手机页面显示两个开关状态。

**通过标准**：身体键、手机、PC 三处状态一致；重启后保持；语音关时功放静音；主动消息关时不再新增。

## 7. P6：PCB（可选，但建议做）

- [ ] 按 `接线表.csv` 画原理图；每个网络用网络标签。
- [ ] 转 PCB，按顶/底摆位摆件；先电源，再关键信号，最后普通信号。
- [ ] 5V ≥1.5mm；3.3V ≥0.6mm；信号 0.25mm；过孔 0.3/0.6。
- [ ] 双面铺地；功放 470µF 靠近喇叭座；麦克风地单独回 3.3V 去耦点。
- [ ] 天线区 `(63,10)–(78,38)` 两层禁铜；左侧 DevKitC USB 缺口、右侧充电口；板框 Ø120。
- [ ] DRC 0 硬错；出 Gerber（RS-274-X，不要 X2）、钻孔 PTH/NPTH 分开、BOM/坐标。
- [ ] 上传嘉立创：2 层、Ø120mm、1.6mm、1oz、绿色、白字、HASL、5 片、不贴 SMT（超出 100mm 免费档）。

**通过标准**：DRC 0 硬错；Gerber 检查通过；板框/孔径/丝印/极性人工复核。

## 8. P7：装配与长测

- [ ] 空板量 5V/3.3V 对地不短路。
- [ ] 只焊 5V 入口，接 5V，量 5V；再焊座/按键/阻容。
- [ ] 插 DevKitC，烧 bring-up：串口 → 屏幕四色 → 摄像头 ID → 麦克风 RMS → 喇叭 1kHz → 按键/LED → INA226。
- [ ] 装壳前纸板 1:1 试装；屏幕/摄像头/麦克风先不上胶。
- [ ] 30 分钟连续对话；10 分钟 WiFi 压力；1 小时待机；断电/上电 20 次；最大音量自激测试。
- [ ] 电源键 20 次开关；语音/主动消息开关重启后保持。

**通过标准**：30 分钟不掉线；1.5 小时续航；按键 20 次可靠；无明显自激；壳内不短路。

## 9. 常见故障顺序

**板子不工作先量电源，再量复位，再量晶振，最后才怀疑程序。** 这个顺序能省 80% 的瞎试。

| 现象 | 先查 |
|---|---|
| 上电没反应 | 电池电压、IP5306 5V、PTC 2A 是否跳、5V 轨/TVS |
| 5V 有、3.3V 没有 | DevKitC 供电、USB 线、LDO |
| 屏幕不亮 | 3.3V、CS 是否接地、DC/RST、SPI 线 |
| 摄像头不认 | 2×9 排针顺序、XCLK/PCLK、3.3V |
| 麦克风没波形 | BCLK/WS、L/R 接地、I2S 配置 |
| 喇叭没声 | SD 电平、5V、I2S 数据、喇叭线 |
| 按键乱跳 | 上拉、地、消抖、TCA9534 地址 |
| I2C 扫不到 | 上拉、地址、摄像头是否占总线 |
| 待机掉电 | 心跳是否在跑、IP5306 KEY 焊盘 |
| 电源键关不掉 | USB 是否插着、软关机是否发完事件 |
