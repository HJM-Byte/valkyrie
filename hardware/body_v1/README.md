# 瓦尔基里 · 身体底板 v1（模块化）

> **v1 已归档为参考。** 2026-11-01 出了 v2：保留本版全部外设，新增电源键、主动消息开关、语音开关，并把电源补成可心跳/可软关/可读电量的一版。先看 [`body_v2/README.md`](../body_v2/README.md) 和 [`单片机身体方案_v2_20261101.md`](../../docs/单片机身体方案_v2_20261101.md)。

这是一套 **ESP32-S3 身体板** 的方案与采购/接线资料：摄像头、麦克风、喇叭、屏幕、WiFi 都从 PC 上拆下来，装到一块 100 mm 圆板上；大脑仍然是 PC 上的现有 Python 程序。

**先看完整方案：** [`robot/docs/单片机身体方案_20261031.md`](../../docs/单片机身体方案_20261031.md)

**实施路线（P0–P6、验收门、PCB 与固件安排）：** [`robot/docs/单片机身体实现路线_20261031.md`](../../docs/单片机身体实现路线_20261031.md)

## 不是什么

**这不是已经布好线、能直接下单的 Gerber。** 板框、摆位、接线、BOM 已经定死；但原理图连线、PCB 走线、DRC、Gerber 还没做。下一轮按接线表把线连完，跑完 `kicad fab`（或立创 EDA 的 DRC/Gerber 检查）才能上传嘉立创。

## 下单顺序（先别急着打板）

1. **先买模块，不画板。** DevKitC + OV2640 + 1.28" 屏 + INMP441 + MAX98357A，用杜邦线按 `接线表.csv` 在桌面上跑通：屏幕亮、摄像头出图、麦克风有波形、喇叭出声。
2. 核对模块实际排针顺序、屏幕供电电压、功放增益。OV2640 的 2×9 排针各家不同，**必须对着丝印一根根核**。
3. 核对没问题，再按 `board_top.png`/`board_bottom.png` 画底板原理图和 PCB；走线宽度：5V 主干 ≥1.5 mm，3.3V ≥0.6 mm，普通信号 0.25 mm。
4. DRC + Gerber 检查过了，再下单。PCB 参数：2 层、Ø100 mm、1.6 mm、1 oz、绿色阻焊、白色丝印、HASL、5 片、不贴 SMT。

## 关键约束

- 主控用 **ESP32-S3-DevKitC-1-N8R8 v1.1**；v1.0 的 RGB LED 在 GPIO48，会和屏幕 CS 冲突。
- WiFi 天线正下方 **15×20 mm 禁铺铜**（两层），外壳必须是塑料，电池别贴天线。
- 摄像头、屏幕、麦克风、功放、电源全部是 3.3V/5V 模块；**屏幕优先 3.3V**，别把 5V 模块直接插上。
- 这版不把充电 IC 焊上板：5V 由现成 IP5306 模块给，电池接模块，底板只做 5V 保护/分配。

## 参考总价

模块 + 电池 + PCB + 接插件大约 **200–260 元**（不含 3D 打印外壳和运费）；具体以实际下单为准。
